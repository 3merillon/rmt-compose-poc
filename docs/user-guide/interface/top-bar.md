# Top bar

![Play, Stop and volume at the left of the toolbar, view controls, gear and menu at the right](/img/top-bar.png)

From the left, **Play/Pause** starts or resumes at the playhead, **Stop** returns to the beginning, and the slider sets master volume. Select empty canvas to park the playhead for another entrance.

## Loop playback

Shift-click Play or hold Play on a touchscreen to loop. The orbiting indicator shows when loop mode is armed. [Transport and repeat transposition](/user-guide/playback/transport#loop-playback)

## View and settings

**Reset View** brings the BaseNote back into view. **Playhead Tracking** locks horizontal panning and centres the playhead. Turn tracking off to use Reset View again. The **gear** opens [Settings](/user-guide/interface/settings).

## The + menu

| Control | Action |
|---|---|
| Undo / Redo | Step through edits in the current session |
| Reorder Module | Renumber the live score and update references |
| Save Module | Download an editable score |
| Export MIDI | Download a performance for a MIDI instrument or DAW |
| Load Module ▾ | Open a file or choose **Reset Default Module** to return to the startup canon |

The menu also links to the documentation, the donation page and the licence. The separate [module bar](/user-guide/interface/module-bar) below it holds the library, live tempo and drop mode.
