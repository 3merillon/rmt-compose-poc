# Tutorials

Start with a score you can hear. In [Your first composition](/getting-started/first-composition), lengthen a blue bass note in the startup canon and hear its effect on the next entrance. In [Reading the canon and its cadences](/tutorials/workflows/canon-and-cadences), follow a pitch reference forward to the next harmony and listen for a common tone across a chord change.

| To practise | Tutorial |
|---|---|
| Place pitches against a tonic | [Build a major scale](/tutorials/beginner/major-scale) |
| Sound several notes at once | [Create a major triad](/tutorials/beginner/major-triad) |
| Link durations, entrances and rests | [Add rhythm](/tutorials/beginner/rhythm) |
| Change a phrase through one note | [Note dependencies](/tutorials/intermediate/dependencies) |
| Move a voice into another register | [Octave manipulation](/tutorials/intermediate/octaves) |
| Lay out bars of different lengths | [Working with measures](/tutorials/intermediate/measures) |
| Keep a phrase for another piece | [Building a module library](/tutorials/workflows/module-library) |

Continue with the [intermediate](/tutorials/intermediate/), [advanced](/tutorials/advanced/) or [workflow](/tutorials/workflows/) lessons. The [expression reference](/reference/expressions/syntax) lists the forms you can type into each note’s Raw field.
